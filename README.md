# systematic-trading-backtesting-framework

## Selecting API for stock data
  - I wanted the data to be as accurate as possible for the success of my project results so I had two options.
    1. yfinance (Python Library, Free)
    2. polygon (API for algo trading, Free or Paid)

  I chose **yfinance** since polygon.io was quite expensive for me to get data sources although it offers nicely cleaned dataset. 
  I needed adjusted prices as well as OHLCV!
